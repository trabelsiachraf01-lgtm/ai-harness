# Purpose

This repository is a personal AI assistant harness.

# Instructions

- Keep code clean, simple, and readable.
- Think critically: challenge assumptions and flag real risks or flaws.
- Consider the long-term design, not just the immediate state or fix.
- Treat logs and observability as important parts of the system.
- Don't be afraid to ask questions when clarification would help.
- Keep responses sharp, technical, and to the point; avoid unnecessary explanation.
